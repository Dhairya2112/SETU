# POOKIE Project — Step-by-Step Implementation Guide

This guide breaks down the development of the POOKIE AI agent into actionable, step-by-step tasks. Follow these steps in order to build the project from scratch.

---

## Phase 1: Core AI & Backend Foundation

Your first goal is to build the "brain" and the backend infrastructure that will support it.

### Step 1: Set Up the Backend Environment
1. **Initialize Project:** Create a new folder for the backend (e.g., `pookie-backend`).
2. **Setup Python:** Create a Python virtual environment (`python -m venv venv` and activate it).
3. **Install Core Libraries:** 
   ```bash
   pip install django djangorestframework celery redis pymongo
   ```
4. **Initialize Django:** Run `django-admin startproject core .` and create a main app `python manage.py startapp agent`.

### Step 2: Implement Wake Word Detection
1. **Install Audio Libraries:** Install PyAudio and OpenWakeWord (`openwakeword`).
2. **Create Listening Script:** Write a standalone Python daemon (`listener.py`) that listens to the microphone continuously and prints "Wake word detected!" when it hears "Hey POOKIE".

### Step 3: Integrate Speech-to-Text (STT)
1. **Install Faster-Whisper:** `pip install faster-whisper`
2. **Connect to Listener:** Update your `listener.py` so that *after* the wake word is detected, it records audio for 5 seconds (or until silence) and passes that audio to faster-whisper.
3. **Print the Output:** The script should now print the transcribed text of what the user said.

### Step 4: Build the LangChain Agent (The Brain)
1. **Install LangChain & Env:** `pip install langchain-groq python-dotenv`. Create a `.env` file and add your `GROQ_API_KEY`.
2. **Create Tools:** Write simple Python functions that the AI can use (e.g., a function to get the current time, a function to search Wikipedia).
3. **Set up the Agent:** Use LangChain's ReAct agent pattern. Feed the STT text from Step 3 into the agent, allow it to use the tools, and capture its final text response.

### Step 5: Add Text-to-Speech (TTS)
1. **Choose TTS Engine:** Install `piper-tts` (for fast offline voice) or `kokoro` for high-quality realistic voice.
2. **Speak the Response:** Take the text generated by the LangChain agent and pass it to the TTS engine to play the audio back to the user.

*(Phase 1 is now fully completed and stabilized with API rate-limit resiliency! We have a working terminal-based AI assistant.)*

---

## Phase 2: Web API & Database

Now, we need to wrap the AI in an API so external interfaces (like a React app) can talk to it.

### Step 6: Setup MongoDB & Data Models
1. **Configure DB:** Connect Django to MongoDB (using `djongo` or `mongoengine`).
2. **Create Models:** Create database schemas for `User`, `ConversationHistory`, and `Settings`.

### Step 7: Build the REST API
1. **Create Endpoints:** Using Django REST Framework, create endpoints like:
   - `POST /api/chat/` (Send a text command to the agent)
   - `GET /api/history/` (Fetch past conversations)
   - `PATCH /api/settings/` (Update user preferences)

### Step 8: Implement WebSockets for Real-Time UI
1. **Install Channels:** `pip install channels daphne` to add WebSocket support to Django.
2. **Create Consumers:** Write a WebSocket consumer that accepts an audio stream or text command, passes it to the AI, and *streams* the AI's response tokens back to the client in real-time.

---

## Phase 3: Desktop App (Windows / Linux) & Web Dashboard

Build the visual interface for users to manage their agent.

### Step 9: Setup React Frontend
1. **Initialize React:** `npm create vite@latest pookie-frontend -- --template react-ts`
2. **Install Tailwind:** Setup Tailwind CSS for styling.
3. **Build the Layout:** Create the sidebar, header, and main chat area using the dark theme aesthetics from the blueprint.

### Step 10: Connect UI to Backend
1. **API Integration:** Use `fetch` or `axios` to connect your React app to the Django REST endpoints (for login, history, etc.).
2. **WebSocket Integration:** Connect to the Django WebSocket to display live text streaming as the AI generates its response.
3. **Voice Visualizer:** Add a library like `framer-motion` to create an animated waveform that reacts when the AI is "listening" or "speaking".

## Phase 4: Mobile App (Android)

Turn the core agent into a mobile experience.

### Step 14: React Native App
1. **Initialize:** `npx react-native init PookieMobile`
2. **Voice Pipeline:** Implement a mobile-friendly voice detection library (like `@react-native-voice/voice`) and a foreground service to keep it alive.
3. **Connect to Cloud API:** Point the mobile app to a hosted version of your Django backend so the agent can be accessed anywhere.

---

## Phase 5: Polish & Deploy

Finalize the application for release.

### Step 15: Security, Marketing & Deployment
1. **Security Audit:** Review all permissions and ensure Level 3 commands trigger OS prompts.
2. **Offline Resilience (NLP):** Train and integrate the DistilBERT intent classifier to ensure system-level commands work entirely offline without LLM API dependency.
3. **Landing Page:** Build a static website (Vite/Tailwind) that explains the permission model and provides download links for your compiled apps.
4. **Dockerize Backend:** Containerize the Django backend and Redis/MongoDB using Docker Compose for your cloud API deployment.
